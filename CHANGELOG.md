# Changelog

Notable changes are documented here using
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) conventions.

## [Unreleased]

### Added

- Non-root, health-checked production container and hardened Compose service.
- Locked `uv` CI with lint, type, test, coverage, security, and dependency gates.

## [0.2.0] - 2026-07-17

### Changed

- Renamed the project to `eidolon-telegram-scraper`.
- Hardened the asynchronous pipeline, configuration, storage, and provider boundaries.
- Added structured AI decisions, evaluation fixtures, and operational health endpoints.

## [0.1.0] - 2026-03-04

### Added

- Initial read-only Telegram monitor with rules, embeddings, LLM classification,
  alerts, daily summaries, and SQLite persistence.
